Read the scores with care
No real Hayuma Cooperative data exists yet, so the models were trained and tested on generated data that imitates a bangus farm. These scores show the pipeline works. They are not evidence of real-world accuracy, which can only be measured after collecting data at the farm.

Next improvements

1. Collect real data
Several weeks of hourly readings and fish samples from Hayuma Cooperative, then retrain.
2. Better oxygen warning
Add longer history, weather and feeding times, and forecast 3 to 6 hours ahead.
3. Compare more models
Random forest, XGBoost and LSTM against the same baselines.
4. Detect sensor faults
Stop stuck or impossible readings from triggering alerts or feeding changes.
5. Explain each alert
Show which readings pushed the model toward a warning.
6. Validate the rules
Have the cooperative and an aquaculture adviser confirm limits and feeding rates.
